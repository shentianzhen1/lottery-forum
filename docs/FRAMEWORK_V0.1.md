# 彩票论坛 Framework V0.1

状态：2026-10-09 指定的框架边界。本文只记录模块和当前证据，不把未实现的模块写成已完成。

钱包、冻结、保证金、手续费和赔率快照都指平台积分，不是现金。当前不实现充值、提现、兑付或用户间转账。

## 1. 工程骨架

- Flutter Android：已有横屏骨架，没有 APK，真机未验。
- FastAPI：已有健康检查、账户、积分和玩法校验。
- PostgreSQL：迁移文件已有。连接代码在未合并的 PR #10，本环境没有实际连上。
- Redis：未引入。只在缓存、限流或任务需求明确时再加。
- Docker：Compose 在 PR #10，本环境没有 Docker。
- GitHub Actions：已有 API 与 Flutter 检查。

## 2. 核心领域模型

- User：注册、登录和角色字段已有。角色尚未用于授权。
- Wallet / Ledger：追加式积分账本、幂等和冻结已有。默认存储是 SQLite。
- Lottery：只有福建 31 选 7 的选号校验，没有彩种配置对象。
- Play：数字选号、排名竞猜和福建 31 选 7 是示例插件。
- Round：未实现。
- Bet：福建 31 选 7 选号记录在未合并的 PR #14，不扣分。固定 10 积分参与只属于另两个示例，是临时切片。
- Settlement：未实现，派奖仍为 0。
- BankerSession：未实现。版主达标开通 API 已有，客户端开通入口未接入；无需人工审核。
- Risk：未实现。

## 3. 彩种扩展框架

已有玩法注册和输入校验。没有独立的彩种定义、渲染器注册表或结算规则注册表。新增玩法仍要改注册代码，不能只交插件包。

## 4. 通用钱包框架

已有余额投影、分录、冻结、解除冻结和幂等键。没有独立事务对象。冻结尚未接入版主保证金，数量未定。

## 5. 投注框架

已有校验。没有投注单、投注明细、赔率快照和生命周期。福建 31 选 7 不走临时扣分。

## 6. 期号框架

未实现。状态机预定为 UPCOMING、OPEN、CLOSED、DRAWN、SETTLING、SETTLED。当前没有开奖数据。

## 7. 坐庄框架

未实现。预定包含坐庄会话、玩法、积分赔率快照、手续费策略、保证金和风险接口。保证金和手续费规则未定，不得自行拍板数值。

## 8. 接口与测试

已有部分 API 测试和 CI。没有独立契约文件、PostgreSQL 集成测试执行记录或迁移实际执行记录。

## 当前顺序

先把已通过检查的选号记录和横屏选号页收进 `main`，再补期号状态。不跳到现金投注、赔付或 Redis。
