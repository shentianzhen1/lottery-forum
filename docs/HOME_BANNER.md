# 首页横幅与公告

状态：信息架构，页面尚未实现。

## 位置

横屏首页中部从上到下是横幅、公告、热门玩法。左侧导航和右侧积分卡不动。宽度低于 960 时仍只提示使用横屏。

## 横幅

只放一块，高度 140 到 160。左侧是标题和说明，右侧是玩法图形。V0.1 固定一条，不做轮播。

- 标题：多种玩法 积分体验
- 说明：积分账户，不提供充值提现

横幅不放充值、提现、中奖金额或外部广告。

## 公告

标题为「平台公告」。首页最多显示 4 条，按置顶优先、发布时间倒序。每行只显示标题、日期和未读点。点「更多」进入完整列表，点单条进入详情。

字段：`id`、`title`、`body`、`published_at`、`pinned`。置顶最多一条。没有数据时显示「暂无公告」，不放示例通知。

公告不扣分，不承载玩法规则，也不触发起算。
