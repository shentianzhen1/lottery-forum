# 首页横幅与公告

状态：信息架构已定；只读 API 已实现（`GET /api/v1/home/banners`、`GET /api/v1/home/announcements`、`GET /api/v1/home/announcements/{id}`）；客户端首页列表已接入；详情页客户端另片。管理后台与编辑入口尚未实现。

## 位置

横屏首页中部从上到下是横幅、公告、热门玩法。左侧导航和右侧积分卡不动。宽度低于 960 时仍只提示使用横屏。

## 横幅轮播

横幅区域高度 140 到 160，一次只显示一张。多于一张时启用轮播，底部显示圆点。

- 默认第一条标题是「多种玩法 积分体验」，说明是「积分账户，不提供充值提现」。
- 最多 5 张。超过的不进入首页轮播。
- 每张字段：`id`、`title`、`subtitle`、`image_key`、`sort_order`、`enabled`。
- 自动切换间隔 5 秒。鼠标悬停、手指按下或键盘聚焦时暂停，离开后继续。
- 圆点和左右边缘可手动切换。切换后重新计时。
- 只有一张时不显示圆点，也不自动切换。
- 没有启用项时返回空列表：客户端不占位、不显示假图。

横幅不放充值、提现、中奖金额或外部广告。点击跳转玩法或公告为产品愿望，当前客户端本片不点跳、不打开外部链接。

## 公告

标题为「平台公告」。首页最多显示 4 条，按置顶优先、发布时间倒序。当前客户端展示标题 + 摘要（取 `body` 前一两行），置顶项标「置顶」。

字段：`id`、`title`、`body`、`published_at`、`pinned`。置顶最多一条。没有数据时显示「暂无公告」，不放示例通知。

单条详情 API 已开放（`GET /home/announcements/{id}`，免登；不存在 404 `ANNOUNCEMENT_NOT_FOUND`）。「更多」完整列表与管理后台仍未实现；客户端详情页另片。

公告不扣分，不承载玩法规则，也不触发起算。
