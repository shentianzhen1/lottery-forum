# 坐庄引擎

状态：未实现。保证金、手续费和赔率都按积分记录。

## 开通

申请版主不需要人工批准。可用积分达到后台门槛即可开通。门槛由后台设置，默认 10000 积分。

开通时冻结所需积分。冻结积分用来计算最高赔付标准，公式未定。未定前不能开放正式赔付。

## 两个入口

- 版主中心：已开通版块、玩法、赔率快照、手续费策略、保证金和风险快照。
- 版主市场：只展示已发布的积分盘口，用户从这里进入投注。

## 对象

- BankerSession：一个版主在某个彩种版块的开放会话。
- BankerOffer：某个玩法在某期的积分赔率快照、`rule_version` 和限额。
- FeePolicy：手续费策略。未定数值前不能启用扣费。

## 约束

版主自己选择彩种版块，并设置该版块的玩法和积分赔率。不能设置后台门槛，也不能改其他版主的配置。保证金冻结后，可用余额下降，账面余额不变。关闭会话不能删除历史赔率快照。
