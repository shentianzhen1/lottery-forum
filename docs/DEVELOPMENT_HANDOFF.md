# 彩票论坛｜新开发窗口交接提示词 V0.4

请继续开发 GitHub 仓库：https://github.com/shentianzhen1/lottery-forum

## 最高优先级约束
**主要页面以横屏为第一设计方向。** 参考 16:9 横屏，同时兼顾 16:10、平板和不同分辨率。禁止把竖屏页面简单拉宽代替横屏设计。首页、玩法中心、玩法详情、积分中心、版主中心、个人中心和后台都必须进行横屏验证。横屏验收是里程碑的正式通过条件。

## 项目定位
- 产品名称固定为「彩票论坛」。
- 用户界面统一使用「版主」「开通版主」「版主中心」；达标即可开通，无需人工审核。
- Android 测试版优先，架构为未来 iOS 留出空间。
- 技术建议为 Flutter + FastAPI + PostgreSQL；先审计现有代码再决定是否采用。
- 玩法采用可插拔设计；账户、权限、积分账本、审计和配置属于平台公共能力。
- 积分必须可追溯。当前范围不实现现金充值、提现、兑付或用户间积分转账/收款。
- 暂不开发聊天、好友、私信和社区动态。
- 产品文案与实际业务必须一致；涉及真实价值或受监管业务先进行合规评估。

## 协作规则
1. 先核对 README、AGENTS.md（如存在）、TODO/任务文档、分支、最新提交、开放 PR 和 CI。
2. GitHub 当前状态优先；聊天中的历史状态必须重新验证。
3. 不推倒重写，不擅自合并 PR、删除分支或执行不可逆操作。
4. 每轮只做一个可验收的开发目标。
5. 不能把未执行的测试说成通过，不能把计划说成已实现。
6. 每项开发任务都写清修改文件、测试命令、结果和后续风险。
7. 主要页面横屏未通过验收，不得标记阶段完成。
